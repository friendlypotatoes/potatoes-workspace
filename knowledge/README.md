# knowledge/ — the OKF v0.2 bundle

The workflows live here as **OKF** (Operational Knowledge Format) v0.2 templates — the same format
and compile semantics as the workspace knowledge compiler, standalone. The bundle is the source; the
generated file is runtime.

```
templates/*.md                     the concepts: frontmatter + a `# Computation` block
generated/answer-templates.json    generated by scripts/okf.mjs, one way — never hand-edited
```

## The format

````yaml
---
type: Attested Computation
title: <the question this answers>
description: <what it covers and where the detail lives>
tags: [template, okf, ...]
status: draft
parameters:
  - { name: version, type: string, required: true, resolve: none, description: "..." }
context: [as_of]
question_patterns:
  - "the words that should reach this template"
reads: [release]
classes_touched: []
answer:
  shape: table
  headline: { value: count, unit: steps, label: "..." }
  columns: [...]
followups:
  - { template: done-gate, params: {}, text: "..." }
verified: [{ by: "human:potatoes", at: 2026-11-12 }]
stale_after: 2027-02-12
generated: { at: 2026-11-17 }
---

<prose>

# Computation

```sh
<the mechanical procedure — commands that fail when the work is broken>
```
````

## The rules (T23 semantics)

- A template is `type: Attested Computation` with a title and a `# Computation` code block. The
  compiler refuses anything else.
- **An agent never verifies.** `verified.by` must start with `human:` and carry a date. A template
  without a human `verified` entry, or past its `stale_after` date, compiles with
  `resolvable = false` and a reason.
- `:name` in a computation is a bind and must be a declared parameter, context or constant. Keep
  stray colons out of computation blocks (a shell command like `npm run x:y` reads as a bind `:y`).
- The generated file records `concept_sha256` per template, the compile is one way: edit the
  template, regenerate.

## Commands

```sh
node scripts/okf.mjs          # compile templates -> generated/answer-templates.json
node scripts/okf.mjs --check  # compile only; fail if the generated file is stale
```
